Hébergement : GitHub Pages
Contact : +243 979 497 516

## Structure

- index.html
- css/style.css
- js/script.js
- images/ (hero, prestations, galerie)

## Photos provisoires

Les photos actuellement dans `images/` et `images/galerie/` sont des placeholders
téléchargés depuis Pexels (licence gratuite, y compris usage commercial) pour
visualiser le site avant d'avoir les vraies photos.

Pour les remplacer : écrase simplement chaque fichier en gardant le même nom
(ou adapte le chemin dans `css/style.css` / `index.html`).
